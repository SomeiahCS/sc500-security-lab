# Azure track icons

The SC-500 Prep track cards use Azure/Microsoft service SVGs sourced from the Azure public service icon set mirrored by `mrpieper/azure-architecture-icons`.

Mappings:

- entra — Microsoft Entra ID Protection
- keyvault — Azure Key Vault
- governance — Azure Policy
- storage — Storage Accounts
- sql — Azure SQL
- networking — Azure Firewall
- ai — Azure OpenAI
- servers — Virtual Machine
- appsec — Azure Kubernetes Service
- defendercloud — Microsoft Defender for Cloud
- sentinel — Microsoft Sentinel
- copilot — AI Studio, used as the closest Azure AI visual for this track

Keep original colors and proportions. These icons are service visuals, not SC-500 Prep branding.
