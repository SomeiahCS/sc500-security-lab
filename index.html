Why I created this

Microsoft security documentation is comprehensive, but learning from documentation alone can feel fragmented. This project was created to bring the important SC-500 concepts into one focused place where they can be explored visually and repeatedly.

The goal is not just to pass an exam. It is to understand why a security control exists, where it lives, what attack path it breaks, and how a security engineer would verify that it is actually working.

Independent learning project. Microsoft product names are used only to describe the technologies being studied.
